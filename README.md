# Eduardo Silva — Barber Website (Cambridge)

Static site ready for Vercel: no framework, no build step.

## Before uploading
1. Instagram buttons are already configured for **@EDZBARBER**: https://www.instagram.com/EDZBARBER/ .
2. Replace the sample Unsplash photos in `index.html` / `style.css` with your real haircut photos when you have permission. Until then the gallery is labelled as inspiration.
3. Check the address and service list; do not show services you do not offer.

## Publish on Vercel
1. Upload these four files to a GitHub repository (keep `index.html` at repository root).
2. In Vercel select **Add New → Project**, import the GitHub repo.
3. Select **Framework Preset: Other**, **Root Directory: .** and **Build Command: none** (disable override).
4. Click **Deploy**. Vercel provides a `.vercel.app` address.

All buttons marked for Instagram open your profile in a new tab. Visitors can then select **Message** in Instagram to DM you. Instagram does not guarantee a public URL that opens a prefilled DM for every account.
